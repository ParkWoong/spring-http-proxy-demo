# HTTP Proxy Extraction / HTTP 프록시 추출

[ENG](#eng) | [KR](#kr)

## ENG

Extracts HTTP forwarding from the original TossController and keeps HttpUtils. RestTemplate.exchange, String bodies, status/content-type handling, and exception handling follow the original code.

### Source and minimal changes

Renamed TossController to ProxyController and ThreeScaleProperties to GatewayProperties. Removed the JWT bypass selection and request-log service from this standalone forwarding example. PropsConfig only registers GatewayProperties. Added localhost settings and tests. Removed the previously generated byte-array proxy and header-filter implementation.

### How it works

Client → ProxyController.toss → HttpUtils.getHeaders/getForwardUri → RestTemplate → upstream. Upstream HTTP errors keep their status/body; other errors return 500 with Proxy failed. The target comes from gateway.origin.

### Run and test

Use Java 17 and Maven 3.6.3+. Run from the repository root:

```sh
mvn clean verify
mvn spring-boot:run
```

Start a sample upstream in another terminal, from a folder with only public sample files:

```sh
python3 -m http.server 9090 --bind 127.0.0.1
```

Then call the running proxy:

```sh
curl -i http://localhost:8080/
```

Set PROXY_UPSTREAM to change the trusted destination. Stop the proxy with Ctrl+C.

### Formatting

All Java files use google-java-format 1.24.0 with the AOSP style: four-space indentation, consistent line breaks, and organized imports.

### Original limits

Original limits remain: String bodies, one value per request header, only content-type copied to responses, and no explicit client timeouts or hop-by-hop header filtering. It is not a general-purpose binary/streaming proxy. Use a trusted localhost upstream with sample requests.

The build keeps Spring Boot 2.6.6 and the original MyBatis/JJWT APIs for source fidelity. Lombok 1.18.36 supports the local Java 17 build. These are legacy dependencies; this extraction is for learning, not a production-ready upgrade. No production integration or load test is included.

## KR

원본 TossController의 HTTP 전달 부분과 HttpUtils를 추출했습니다. RestTemplate.exchange, String 본문, 상태·Content-Type 처리 및 예외 처리는 원본 코드를 따릅니다.

### 원본과 최소 변경 사항

TossController를 ProxyController로, ThreeScaleProperties를 GatewayProperties로 변경했습니다. 독립적인 전달 예제에서 JWT 우회 대상 선택과 요청 로그 서비스를 분리했습니다. PropsConfig는 GatewayProperties만 등록합니다. localhost 설정과 테스트를 추가했습니다. 이전에 새로 작성한 byte[] 프록시와 헤더 필터 구현은 제거했습니다.

### 코드 설명

클라이언트 → ProxyController.toss → HttpUtils.getHeaders/getForwardUri → RestTemplate → upstream 순서입니다. upstream HTTP 오류는 상태·본문을 유지하고 나머지 오류는 500과 Proxy failed를 반환합니다. 대상 주소는 gateway.origin 설정에서 읽습니다.

### 실행과 테스트

Java 17, Maven 3.6.3 이상을 사용합니다. 저장소 루트에서 실행하세요:

```sh
mvn clean verify
mvn spring-boot:run
```

공개 가능한 샘플 파일만 있는 폴더에서 별도 터미널로 upstream을 실행하세요:

```sh
python3 -m http.server 9090 --bind 127.0.0.1
```

실행 중인 프록시를 호출하세요:

```sh
curl -i http://localhost:8080/
```

신뢰하는 대상 서버 변경은 PROXY_UPSTREAM으로 설정합니다. Ctrl+C로 프록시를 종료합니다.

### 코드 포맷

전체 Java 파일에 google-java-format 1.24.0의 AOSP 스타일을 적용했습니다. 들여쓰기 4칸, 일관된 줄바꿈 및 import 정리를 사용합니다.

### 유지한 원본 동작과 제한

원본 제한을 유지합니다. 본문은 String이며 요청 헤더는 이름별 값 하나를 사용하고 응답 헤더는 Content-Type만 복사합니다. 명시적 클라이언트 타임아웃이나 연결 구간 전용 헤더 제거는 없습니다. 범용 바이너리·스트리밍 프록시가 아니며 신뢰하는 localhost 서버와 샘플 요청으로 실습하세요.

원본 코드 보존을 위해 Spring Boot 2.6.6과 원본 MyBatis/JJWT API를 사용합니다. 로컬 Java 17 빌드를 위해 Lombok 1.18.36을 적용했습니다. 레거시 의존성을 사용하는 학습용 추출본이며 운영용 업그레이드가 아닙니다. 운영 연동 및 부하 테스트는 포함하지 않습니다.
